# ADR-001 - Session rollouts are mandatory fallback evidence

Status: ACCEPTED
Date: 2026-09-27

## Context

Experiment 001 diagnostic trace contained only four bookkeeping/protocol events
while standard Codex session rollouts contained the actual model, tool, token,
subagent and terminal-status activity.

## Decision

V0.1 treats standard session rollouts as first-class evidence.

Diagnostic trace remains valuable when healthy but can no longer be the sole
source required by analyze/compare.

Every experiment finisher must capture/discover both source classes when available.

## Consequences

Positive:
- normal Desktop runs remain measurable when trace mode is partial;
- subagents and usage-limit failures become visible;
- experiments become resilient to trace regressions.

Cost:
- session tool parsing must be hardened;
- cross-source reconciliation becomes required.
