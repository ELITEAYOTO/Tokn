# Tokn V0.1 - Implementation Plan

Status: **IN PROGRESS - P0-P7 DONE / P8 IN PROGRESS**
Date: 2026-09-29

## Objective

Make Tokn trustworthy on real Codex/Astra runs before any active optimization.

V0.1 is a measurement-hardening release.
It does not optimize Astra.

## Definition of done

V0.1 is done when the Experiment 001 golden replay automatically reports:
- 1 parent + 3 subagents;
- 80 usage records;
- logical total 5,311,758;
- uncached input 226,025;
- terminal INCOMPLETE_USAGE_LIMIT;
- diagnostic PARTIAL with session fallback;
- policy observed FAIL, never false PASS;
- policy enforcement accurately qualified;
- B07-C_WORKING\PROJECT selected;
- diff 13 added / 4 modified / 0 removed;
- verify:local PASS on B07-C;
- experiment verdict INSTRUMENTATION_ONLY;
- one self-contained runner evidence folder;
- fmt/clippy/tests/release/privacy gates PASS.

## Non-goals

Not in V0.1:
- active context reduction;
- hard output-token limiting;
- command rewriting;
- RAG/embeddings;
- Project Memory;
- Context Compiler;
- optimization plugin;
- GUI/daemon.

These belong after reliable measurement and findings.
